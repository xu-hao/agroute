# Project image provenance

## Branching-route mark

[route.svg](route.svg) is agroute's project mark, used in the repository README and
documentation homepage. Two branching levels connect one input to two routing
nodes, each of which branches to two destinations. The nodes represent choices
among routes rather than labels for specific providers.

The SVG was authored directly by Codex on 2026-11-14 following the user's choice of
a branching-route symbol in the same geometric black-and-white style as howhard.
The artwork uses exactly two colors: solid black (`#000000`) and solid white
(`#ffffff`). It has no shading, gradients, texture, fonts, embedded raster image
or external dependencies. No third-party artwork was used.

The source has a 512 by 512 view box, a 17-unit uniform line and seven circular nodes
of radius 22. Smooth curves connect both branching levels to their shared stems.
The plain white background keeps the black mark legible in light and dark interfaces.
Browsers may antialias edges; the vector artwork itself defines only the two colors.

The SVG's SHA-256 checksum is
`c8433e404eb7c7f8b8c5db764b921ce92044981f708974e9a7ec45922f6828c2`.

[Issue #48](https://github.com/xu-hao/agroute/issues/48) tracks the branching-route
mark and documentation organization.

[Issue #52](https://github.com/xu-hao/agroute/issues/52) tracks extending the mark
to two branching levels while preserving its geometric style, line weight and two colors.
